# 刺客对战奇美拉 Demo

直接打开 `index.html` 即可游玩，无需安装依赖。

## 界面

- 参考《杀戮尖塔》的信息分区，不套用其战斗规则。
- 中央战场突出奇美拉、三颗头的生命与目标选择。
- 右侧在玩家出牌前公开完整的 3D12 行动表。
- 每次结算会高亮骰面、来源头部、技能、伤害计算和状态结果。
- 每条结算会弹出独立结果面板，点击“继续结算”后才推进到下一条。
- 底部采用横向手牌、行动力、牌堆与结束阶段控制。
- 斗兽场照片作为可见的暗色战场背景。
- 首次交互后播放音量更明显的快节奏程序化战斗鼓点，可随时静音。
- 可点击“牌库”“弃牌”“消耗”查看三个牌堆中的完整卡牌。

## 已实现规则

- 当前为 34 张测试牌库：普通攻击 ×4、防御 ×4、毒匕首 ×3、龙之威仪 ×2、龙之吐息 ×2，其余原卡各 1。
- 新增搜索、血色交易、连刺、淬毒飞溅、烟幕、佯攻各 1 张。
- 测试牌库超过常规 30 张上限，正式版需要裁剪或取得规则例外。
- 龙头：3 气吼功、6 法术反射、9 振翅、10 火焰吐息。
- 狮头：1 啃咬、2 爪击、8 尾击。
- 羊头：4 角撞、5 降咒、7 恶毒嘲笑、11 争吵。
- 三颗头各 20 点生命；单体攻击指定头部，范围攻击伤害全部存活头部。
- 对应头部死亡后骰面作废；全部头部死亡才获胜。
- 任一骰面出现 12 时重投全部骰子，直到没有 12。
- 2+9 替换为地球上投；任一相关头部死亡时不会触发。
- 振翅提供一次本回合玩家攻击格挡。
- 三颗头在同一回合都完成行动后，奇美拉下回合获得劣势。
- 玩家和敌人的攻击分别抽取攻击修正牌；范围攻击逐目标抽取。
- 结算顺序：玩家技能牌 → 敌人非攻击行动 → 玩家攻击牌 → 敌人攻击行动。
- 初始抽 5 张；之后每轮补充 3 点行动力并抽 2 张。

## 状态口径

- 倒地：下回合消耗 2 点行动力站起后才能使用卡牌。
- 劣势：下回合伤害骰只使用减攻击修正。
- 睡眠：回合开始投 D6，单数解除，偶数跳过回合；受伤解除。
- 缓慢：每层使卡牌费用 +1，回合结束移除一层。
- 麻痹：PK 阶段每张玩家卡牌有 50% 概率失效，回合结束移除。
- 流血：每层在回合结束造成 1 点伤害，然后移除一层。
- 中毒：每颗头独立计算，每层在回合结束造成 2 点毒素伤害。

## 扩展牌

- 搜索：1 行动力，立即抽 3 张，视为即时牌。
- 血色交易：0 行动力，立即失去 5 点生命并获得 2 点行动力。
- 连刺：2 行动力，对同一头部造成 3 次 2 点穿刺伤害。
- 淬毒飞溅：2 行动力，造成 4 点穿刺伤害，并让其余头部各获得 1 层中毒。
- 烟幕：1 行动力，本回合获得 35% 闪避；成功闪避一次后抽 1 张。
- 佯攻：1 行动力，抽 1 张；本回合下一张攻击牌伤害 +2。
